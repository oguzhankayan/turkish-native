# Security Policy

Turkish Native is primarily a Markdown-based agent skill, but the repository also includes package manifests and validation scripts.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability that could put users at risk.

Report it privately to:

`oguzhankayan@outlook.com.tr`

Include:

- the affected file or component,
- the impact you expect,
- reproduction steps where possible,
- any suggested mitigation.

## Scope

Security reports are appropriate for issues such as:

- malicious or unsafe package behavior,
- command injection in repository scripts,
- compromised installation instructions,
- dependency or packaging issues that could execute unintended code.

Language-quality disagreements and prompt-behavior bugs should be reported through normal GitHub issues instead.
