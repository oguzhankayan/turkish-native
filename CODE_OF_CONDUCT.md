# Code of Conduct

## Our standard

Turkish Native is a language project. Discussions about dialect, register, loanwords, regional usage, and style can involve legitimate disagreement. Treat those disagreements as linguistic questions, not judgments about people.

Participants should:

- be specific about the text or rule being discussed,
- distinguish personal preference from a reusable language pattern,
- welcome evidence and counterexamples,
- avoid insults, harassment, discriminatory language, and personal attacks,
- respect contributors' privacy and intellectual property.

## Scope

This code applies to repository issues, pull requests, reviews, discussions, and other project spaces managed by the maintainers.

## Enforcement

Report serious conduct issues privately to the maintainer at `oguzhankayan@outlook.com.tr`. Reports will be reviewed in good faith. Maintainers may edit, hide, lock, or remove contributions and may restrict participation when necessary to keep project spaces constructive.
